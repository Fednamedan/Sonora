# Sonora

Музыкальный плеер для Android с каталогом внутри приложения: ищете треки, слушаете, сохраняете в избранное и плейлисты, скачиваете для офлайна. Ни сервера, ни ключей, ни аккаунта не нужно.

## Откуда музыка

Каталог собирается из нескольких открытых источников: [Audius](https://audius.co), Internet Archive и (по ключу, см. `data/Config.kt`) Jamendo: независимые артисты, электронная музыка, хип-хоп, лоу-фай, инди и многое другое. Это **не** каталог мейнстрима: там нет крупных лейблов, как в Яндекс Музыке или Spotify. Лицензии на такую музыку есть только у платных сервисов, поэтому легально получить её через открытый API нельзя.

Источник изолирован в `data/AudiusApi.kt`. Если появится другой легальный каталог, достаточно написать для него клиент с теми же методами `trending`, `search`, `streamUrl`.

## Сборка

1. Установите Android Studio (актуальную версию).
2. `File → Open` и выберите папку проекта, дождитесь синхронизации Gradle (Studio сама скачает Gradle 8.9 и зависимости).
3. Подключите телефон (Android 8.0+) с включённой отладкой по USB или запустите эмулятор и нажмите ▶ Run.
4. Если Studio предложит обновить версии Gradle и плагина, соглашайтесь.

`gradlew` и `gradle-wrapper.jar` в архиве нет: Studio создаёт их сама, либо выполните `gradle wrapper` в корне проекта.

Чтобы получить apk для установки без Studio: `Build → Build Bundle(s) / APK(s) → Build APK(s)`.

## Что умеет

- **Главная**: «Моя волна», жанры, недавно слушали, популярное за неделю.
- **«Моя волна»**: бесконечное радио. Считает ваши вкусы по лайкам и истории (жанры и теги), подбирает свежие треки и не повторяет недавно игравшие. Пока лайков нет, играет популярное из разных жанров.
- **Радио по жанру и по треку**: из экрана жанра, меню трека или плеера.
- **Поиск** по трекам, исполнителям и жанрам.
- **Библиотека**: избранное, плейлисты (создать, переименовать, удалить), загрузки, история.
- **Офлайн**: «Скачать» сохраняет трек в память приложения, дальше он играет без интернета.
- **Плеер**: фон, уведомление, экран блокировки, наушники, очередь (добавить, «играть следующим», убрать), перемешивание, повтор, таймер сна.

## Структура

- `data/AudiusApi.kt` — клиент каталога.
- `data/Store.kt` — избранное, плейлисты, история (один JSON-файл).
- `data/Downloads.kt` — офлайн-загрузки.
- `data/Radio.kt` — «Моя волна» и радио.
- `playback/PlaybackService.kt` — ExoPlayer + MediaSession (Media3), подстановка свежих ссылок на поток.
- `playback/PlayerController.kt` — очередь, радио, таймер сна, учёт прослушиваний.
- `ui/` — экраны на Jetpack Compose.
